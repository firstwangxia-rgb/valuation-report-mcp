# 本地知识库

该目录只提供分类骨架。真实资料默认被 `.gitignore` 排除，不应提交到公共仓库。

| 子目录 | 建议内容 |
|---|---|
| `准则/` | 有合法使用权且确认现行有效的资产评估准则或摘录 |
| `评估报告/` | 已获授权、完成必要脱敏的历史案例 |
| `评估说明/` | 工作说明、方法说明和内部模板 |
| `公司档案/` | 由公开来源整理、带 URL 和日期的公司信息 |

支持 `.md`、`.txt`、`.pdf` 和 `.docx`。扫描版 PDF 需要先由外部工具完成 OCR。

知识库材料不随本项目代码采用 MIT 许可证。上传或共享前请自行核验版权、保密义务、个人信息和数据跨境要求。
